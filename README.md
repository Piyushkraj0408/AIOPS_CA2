# Breast Cancer Classification — MLOps Demo

An end-to-end educational ML project: model training, `joblib` persistence, FastAPI inference, Docker, pytest, and GitHub Actions CI.

> **Safety:** This project is for learning only. It is not a medical device and must not be used for diagnosis or treatment decisions.

## Dataset

Uses scikit-learn's bundled copy of the UCI Breast Cancer Wisconsin (Diagnostic) dataset (569 rows, 30 numeric features). This is a convenient reproducible source for the same canonical dataset. If your assignment strictly requires a Kaggle download, see the notebook note and import the Kaggle CSV instead.

## Project layout

- `notebooks/train_model.ipynb`: training and evaluation notebook (run in Colab)
- `app/model.joblib`: fitted pipeline and feature metadata
- `app/main.py`: FastAPI prediction API
- `tests/test_api.py`: endpoint tests
- `Dockerfile`: container image
- `.github/workflows/ci.yml`: test + Docker build on push / pull request

## 1. Local setup (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 2. Run tests

```powershell
python -m pytest -v
```

## 3. Start the API locally

```powershell
uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000/docs`, or check `http://127.0.0.1:8000/health`.

## 4. Try a prediction

The request must contain all 30 feature names. For a ready-to-send example, run:

```powershell
python -c "from sklearn.datasets import load_breast_cancer; import json; d=load_breast_cancer(as_frame=True); print(json.dumps({'features': {k: float(v) for k,v in d.data.iloc[0].items()}}))"
```

Copy the printed JSON into the `/predict` endpoint in Swagger UI.

## 5. Build and run with Docker

```powershell
docker build -t mlops-breast-cancer .
docker run --rm -p 8000:8000 mlops-breast-cancer
```

Then open `http://localhost:8000/docs`. Keep the terminal running while you test.

## 6. Push to GitHub

Create an empty repository named `mlops-breast-cancer` on GitHub (do not add a README if you already have one locally), then:

```powershell
git init
git add .
git commit -m "Build breast cancer ML API with Docker and CI"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mlops-breast-cancer.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username. Do not commit passwords or tokens.

## 7. Confirm CI passed

Open your repository on GitHub → **Actions** → **ML API CI**. Confirm the latest run is green and both **Run API tests** and **Build Docker image** passed. A local pass does not prove the hosted workflow passed.

## Model artifact note

`app/model.joblib` is generated by the training notebook. Keep the notebook and artifact in sync; retrain and replace the artifact whenever the feature schema or training pipeline changes. Only load joblib files you trust.
